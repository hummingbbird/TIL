# [LV. 1] 유연근무제

> 2025 프로그래머스 코드챌린지 1차 예선 기출문제

[🔎 문제 보러가기](https://school.programmers.co.kr/learn/courses/30/lessons/388351?utm_source=gemini)

## 문제 설명

프로그래머스 사이트를 운영하는 그렙에서는 재택근무와 함께 출근 희망 시각을 자유롭게 정하는 유연근무제를 시행하고 있습니다. 제도 정착을 위해 일주일 동안 직원이 설정한 출근 희망 시각 늦지 않게 출근한 직원에게 상품을 주는 이벤트를 진행하려 합니다.

* **직원들의 출근 규칙**:
* 직원은 매주 월요일부터 금요일까지 5일 동안 출근을 해야 합니다. (토요일, 일요일 주말은 이벤트 심사에서 제외됩니다.)
* 각 직원은 자신이 설정한 출근 희망 시각 **늦어도 10분 뒤**까지는 출근해야 지각으로 처리되지 않습니다. (예를 들어 희망 시각이 `855`라면, `905`까지 출근해야 합니다.)
* 주말(토, 일)을 제외한 7일 중 하루라도 지각을 하는 경우 상품을 받을 수 없습니다.



직원들의 출근 희망 시각을 담은 정수 배열 `schedules`, 일주일 동안 매일 출근한 시각이 담긴 2차원 정수 배열 `timelogs`, 이벤트를 시작한 요일을 나타내는 정수 `startday`가 매개변수로 주어질 때, 상품을 받을 웰빙 상품 지급 대상 직원 수를 return 하도록 solution 함수를 완성해주세요.

### 제한사항

* `schedules`의 길이(= 직원의 수)는 $1$ 이상 $1,000$ 이하입니다.
* `schedules[i]`는 각 직원이 정한 출근 희망 시각이며, 시와 분을 나타냅니다. (예: `10시 0분`은 `1000`, `9시 55분`은 `955`로 표현됩니다.)
* 시는 $1$ 이상 $23$ 이하이며, 분은 $0$ 이상 $59$ 이하입니다.
* 분은 항상 두 자리 수로 표현되며, 10분 미만인 경우 앞자리 `0`이 생략될 수 있습니다. (예: `9시 5분` -> `905`)


* `timelogs`의 행의 길이는 `schedules`의 길이와 같습니다.
* `timelogs`의 열의 길이는 $7$입니다. (`timelogs[i]`는 $i$번째 직원의 월요일부터 일요일까지 7일 동안의 출근 기록입니다.)
* 출근 시각 형식은 `schedules`와 동일합니다.


* `startday`는 $1$부터 $7$까지의 정수이며, 각각 월요일부터 일요일을 의미합니다. (1: 월요일, 2: 화요일, ..., 7: 일요일)

## 입출력 예

| schedules | timelogs | startday | return |
| --- | --- | --- | --- |
| `[700, 800, 1100]` | `[[710, 2359, 1050, 700, 950, 630, 500], [800, 810, 900, 800, 800, 800, 800], [1100, 1130, 1100, 1100, 1100, 1100, 1100]]` | `5` | `3` |
| `[730, 855]` | `[[700, 700, 700, 700, 700, 700, 700], [900, 901, 902, 903, 904, 905, 906]]` | `1` | `1` |

# 💡 접근 방법 및 풀이 과정

구현 문제군. 핵심 포인트는 크게 두 가지다.

1. **지각 마지노선 시간 계산하기**
- 출근 희망 시각(`schedules[i]`)에 10분을 더해주는 작업이 필요하다. (이때 분(minute) 단위가 60분을 넘어가면 시간을 1 올려주고 분에서 60을 빼주어야함!!)

2. **주말(토, 일) 건너뛰기**
- `startday`를 기준으로 7일간의 요일을 판단할 때, 토요일과 일요일은 이벤트 심사에서 제외해야 하므로 검사 대상에서 빼주거나 `continue`로 건너뛰어야 한다.


<br>
<br>

## 💡 그래서 답은

```python
def solution(schedules, timelogs, startday):
    answer = 0
    
    for i in range(len(schedules)):
        # 1. 지각 마지노선 시간 계산
        sched = schedules[i]
        hour = sched // 100
        minute = sched % 100 + 10
        if minute >= 60:
            hour += 1
            minute -= 60
        limit_time = hour * 100 + minute
        
        # 2. 출근 기록 확인
        is_success = True
        for j in range(7):
            current_day = (startday + j - 1) % 7
            
            # 토, 일은 제외
            if current_day == 5 or current_day == 6:
                continue
                
            # 지각
            if timelogs[i][j] > limit_time:
                is_success = False
                break
                
        if is_success:
            answer += 1
            
    return answer

```
