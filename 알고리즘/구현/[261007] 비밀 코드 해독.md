## 문제 설명

1부터 $n$까지의 정수가 적힌 번호들 중 서로 다른 5개의 정수를 뽑아 비밀 코드를 만듭니다. 비밀 코드를 알아내기 위해 $m$번의 시도를 하였으며, 각 시도마다 5개의 정수를 골라 제출했을 때 비밀 코드의 번호 중 몇 개가 포함되어 있는지를 결과로 받았습니다.

* **비밀 코드 규칙**:
* 1 이상 $n$ 이하의 정수 중 서로 다른 5개의 정수로 이루어져 있습니다.
* 숫자의 순서는 상관없습니다.


* **목표**:
* $m$번의 시도 기록(제출한 5개의 정수 목록 `q`, 그리고 각 시도마다 포함된 비밀 코드 개수의 결과 `ans`)이 주어질 때, 조건을 모두 만족하는 **가능한 비밀 코드의 총 개수**를 구해야 합니다.



### 제한사항

* `n`은 $10$ 이상 $30$ 이하인 정수입니다.
* `m`은 $1$ 이상 $10$ 이하인 정수입니다.
* `q`의 길이는 `m`입니다.
* `q[i]`는 $i번째$ 시도에 고른 5개의 정수가 담긴 배열이며, 원소는 오름차순으로 정렬되어 있습니다.


* `ans`의 길이는 `m`입니다.
* `ans[i]`는 $i번째$ 시도에 고른 5개의 정수 중 비밀 코드에 포함된 숫자의 개수입니다.



## 입출력 예

| n | m | q | ans | return |
| --- | --- | --- | --- | --- |
| `10` | `3` | `[[1, 2, 3, 4, 5], [1, 2, 3, 6, 7], [8, 9, 10, 1, 2]]` | `[2, 2, 1]` | `3` |
| `20` | `4` | `[[1, 2, 3, 4, 5], [1, 3, 5, 7, 9], [2, 4, 6, 8, 10], [11, 12, 13, 14, 15]]` | `[2, 3, 2, 0]` | `10` |

# 💡 접근 방법 및 풀이 과정

n이 최대라고 가정하였을 때, 즉 1~30의 숫자로 5개의 숫자를 골라 순서대로 배열하는 경우의 수를 구해보면 30 * 29 * 28 * 27 * 26 = 17,100,720 이다. 억이 넘어가지 않는다면 전체 탐색을 해도 무리없이 문제를 풀 수 있다. 또한 암만 생각해도 다른 방법으로는 가능한 숫자 조합을 구할 수 없다고 생각했기 때문에 이렇게 해결했다.

1. 1~n까지의 숫자로 모든 조합 구하기
2. 각각의 조합과 q를 비교(반복문)하여 같은 원소의 개수 리스트 구하기
3. 해당 리스트가 ans와 같다면 answer += 1

결국 이 문제의 핵심은 1. 조합을 어떻게 구할 것인가 2. 같은 원소의 개수를 어떻게 구할 것인가 이다. 파이썬의 다양한 라이브러리를 잘 활용할 줄 알아야 아주 그냥 날아다닐 수 있다 .. !!! 이번 문제에서 새롭게 알게 된 방법은 크게 2가지이다.

1. **조합 구하는 법: combinations 사용하기**
```python
from itertools import combinations

nums = [i for i in range(1, n+1)]
arrs = list(combinations(nums, 5))

```

<br>

2. 두 시퀀스 자료형의 같은 원소 개수 구하기(set, 교집합 활용)
```python
# set으로 변환 후, 교집합(&) 연산을 해주면 쉽게 두 배열의 겹치는 원소의 개수를 구할 수 있음
len(set(arr1) & set(arr2))

```

<br>
<br>

# 💡 그래서 답은

```python
from itertools import combinations

def solution(n, q, ans):
    nums = [i for i in range(1, n+1)]
    arrs = list(combinations(nums, 5))
    answer, m = 0, len(q)
    
    for arr in arrs:
        tmp = []
        for i in range(m):
            tmp.append(len(set(q[i]) & set(arr)))
        if tmp == ans:
            answer += 1
    return answer

```
