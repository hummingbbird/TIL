## 문제 설명

창고에 알파벳이 적힌 컨테이너들이 2차원 그리드 형태로 쌓여 있습니다. 사용자들의 요청(`requests`)에 따라 지게차나 크레인을 동원해 컨테이너를 꺼내고 빈 공간(`"0"`)으로 만듭니다.

<!-- 크레인 이미지 삽입 -->

* **컨테이너 출고 규칙**:
* **지게차 (`알파벳 1개`)**: 외부 공기와 맞닿아 있는(접근 가능한) 해당 알파벳의 컨테이너들만 골라서 꺼냅니다. (창고 테두리 또는 이미 빈 공간이 된 곳을 통해 바깥 공기와 연결되어 있어야 합니다.)
* **크레인 (`알파벳 2개, 예: "AA"`)**: 위치와 상관없이 창고 안에 있는 해당 알파벳의 모든 컨테이너를 한 번에 꺼냅니다.
* 컨테이너가 꺼내진 자리는 빈 공간(`"0"`)이 됩니다.



### 제한사항

* `storage`의 길이는 `2` 이상 `50` 이하이며, 각 행의 길이는 `2` 이상 `50` 이하입니다.
* `storage`의 원소는 알파벳 대문자로 이루어져 있습니다.
* `requests`의 길이는 `1` 이상 `100` 이하입니다.
* 요청의 길이는 1인 경우(지게차) 또는 2인 경우(크레인)가 있습니다.



## 입출력 예

| storage | requests | return |
| --- | --- | --- |
| `["AZWQY", "CAABX", "BBDDA", "ACACA"]` | `["A", "BB", "A"]` | `11` |
| `["HAH", "HWH", "HAH"]` | `["H", "HW", "H"]` | `4` |

## 4. bfs를 적용한 jigecha 함수 구현

전체 흐름은 다음과 같다. 사실 가장 중요한 건 visited를 True로 바꾸는 조건, 정상범위인지 확인하는 조건처럼 이런 세세한 조건들이라 빠르게 보겠습니다.

```markdown
1. 주변에 "0"으로 감싸기(반복문 돌 때마다 i j 범위 검사하지 않기 위함(같은 상황으로 만들기 위함?)) (여기서 "0"은 외부 공기와 같은 의미다)

2. visited, deque 세팅

3. 한 바퀴 싹 돌면서 테두리 친구들("0", 즉 공기)은 True로 바꿔서 초기 세팅

4. 본격적으로 while문을 통한 bfs 진행
    - 2차원 배열이므로 상하좌우 탐색
    - 조건: nx, ny가 범위 안이고, con[nx][ny] == "0"이면 (즉, 공기에 닿아있으면) True로 변경

5. visited 이용해서 본격적인 뽑기 작업 진행

6. 공기 없애주고 return
```

<br>

그리하여 지게차 함수 전체 코드는 아래와 같다. (전처리/후처리 해줘야할 게 많아서 생각보다 길다..)

```python
from collections import deque

# bfs를 사용한 지게차 구현
def jigecha(con, req):
    n, m = len(con), len(con[0])
    # 1. 0으로 감싸기
    for i in range(n):
        con[i] = ["0"] + list(con[i]) + ["0"] 
    con.insert(0, ["0"] * (m + 2))
    con.append(["0"] * (m + 2))
    
    
    n, m = len(con), len(con[0])
    # 2. visited(공기 닿아 있는지 리스트) 준비
    visited = [[False for _ in range(m)] for _ in range(n)]
    queue = deque([])
    
    # 3. 테두리 True로 변경 후 queue에 담기
    for i in range(n):
        for j in range(m):
            if i == 0 or j == 0 or i == n-1 or j == m-1:
                visited[i][j] = True
                queue.append((i, j))
    
    # 4. visited 완성하기
    while queue:
        dx = [-1, 1, 0, 0]
        dy = [0, 0, -1, 1]
        x, y = queue.popleft()
        for i in range(4):
            nx = x + dx[i]
            ny = y + dy[i]
            
            if 0 <= nx < n and 0 <= ny < m and visited[nx][ny] == False and con[nx][ny] == "0":
                visited[nx][ny] = True
                queue.append((nx, ny))
    
    # 5. 완성한 visited 기반으로 뽑기 작업 진행
    change = []
    for i in range(1, n):
        for j in range(1, m):
            if con[i][j] == req and (visited[i-1][j] or visited[i+1][j] or visited[i][j-1] or visited[i][j+1]):
                change.append((i, j))
                
    # 6. 마무리 (0으로 변환 후 테두리 없애고 return)
    for c in change:
        x, y = c
        con[x][y] = "0"
    con.pop()
    con.pop(0)
    for i in range(len(con)):
        con[i] = con[i][1:-1]
    
    return con

```

## 5. crain 구현

crain은 매우 쉽다! 그냥 한바꾸 돌면서 뽑아주면 된다. 이 때 파이썬에서 문자열은 **불변(Immutable) 자료형**이라는 점을 주의해야 한다. 그래서 나는 list()로 감싸서 배열 형태로 변환해준 뒤 처리해주었다.

```python
def crain(con, req): 
    n, m = len(con), len(con[0])
    
    # 1.문자열 -> 리스트 타입으로 변경
    for i in range(n):
        con[i] = list(con[i])
        
    # 2. 다 뽑아부러
    for i in range(n):
        for j in range(m):
            if con[i][j] == req:
                con[i][j] = "0"
    return con

```

def solution(storage, requests):
    # 1. 명령어 실행
    for req in requests:
        # case1: 지게차
        if len(req) == 1:
            storage = jigecha(storage, req)
        # case2: 크레인
        else: 
            storage = crain(storage, req[0])

    # 2. 남은 컨테이너 수 return
    n, m = len(storage), len(storage[0])
    answer = 0

        for j in range(m):
            if storage[i][j] != "0":
                answer += 1

    return answer
