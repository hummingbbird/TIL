## 문제 설명

한 자리 숫자가 적힌 종이 조각이 흩어져 있습니다. 파인토이의 종이 조각들을 붙여 소수를 몇 개 만들 수 있는지 알아내려 합니다.

각 종이 조각에 적힌 숫자가 적힌 문자열 `numbers`가 주어졌을 때, 종이 조각으로 만들 수 있는 소수가 몇 개인지 return 하도록 solution 함수를 완성해주세요.

### 제한사항

* `numbers`는 길이 1 이상 7 이하인 문자열입니다.
* `numbers`는 0~9까지의 숫자만으로 이루어져 있습니다.
* "013"은 0, 1, 3 숫자가 적힌 종이 조각이 흩어져있다는 뜻입니다.

## 입출력 예

| numbers | return |
| --- | --- |
| `"17"` | `3` |
| `"011"` | `2` |

---

### 입출력 예 설명

#### 입출력 예 #1

* [1, 7]으로는 소수 [7, 17, 71]를 만들 수 있습니다.

#### 입출력 예 #2

* [0, 1, 1]로는 소수 [11, 101]를 만들 수 있습니다.
* 11과 011은 같은 숫자로 취급합니다.

### 1. 소수 판별 함수
이것은 .. 쉽다. 그냥 과거의 기억을 더듬어 만들었다. 분명히 '**절반+1만큼만 돌려도 충분히 판별 가능**'이었던 게 기억이 나서 대충 더듬더듬 짰는데 된 듯. 20짤 때 이걸 왜 하나 하면서 이것저것 풀었는데 풀길 잘한 듯 하핰!!! 암튼 그랬다. (일기쓰고 앉앗네)

```python 
def isPrime(num):
    if num < 2:
        return False
    for i in range(2, (num//2)+1):
        if num % i == 0:
            return False
    return True
```

### 2. DFS 함수(feat. 백트래킹)
일단 짚고 넘어가야 하는 부분이 있다. 입출력 예제를 보면 '**'012'와 '12'는 같은 숫자로 취급해야 한다**'는 설명이 있다. 이처럼 0이 가장 앞에 왔을 때를 고려하여 예외처리를 해주어야 한다. 다만 파이썬의 경우 `int("012")` => `12` 가 되기 때문에 어렵지 않다 ^^ 또한 같은 숫자가 두개 주어진 경우(ex) 1, 1, 9)에 두번 탐색하지 않도록도 처리를 해주어야 한다. 이것은 set으로 해결 가능 ~ 그리하여

> 1. 경우의 수를 관리하는 자료형은 중복 방지를 위해 set 을 사용한다.
> 2. 0 예외 처리를 위해 set에 저장할 땐 int를 통해 정수로 변환한 후, 저장한다.

그 후 본격적으로 dfs 함수를 만든다. 이 때 새로운 개념 **백트래킹**이 등장한다 !!!!!

> ### 🧩 **백트래킹이란?**
>
>모든 경우의 수를 탐색하되, 조건에 맞지 않거나 이미 탐색한 불필요한 길은 더 이상 가지 않고 되돌아와서 다른 길을 탐색하는 기법이다. 흔히 '**가지치기(Pruning)**'라고도 부른다.
>
> 코드로 구현할 때는 보통 다음의 세 단계를 거친다. 
>
> 1. **선택하기 (Choose)**: 다음 단계로 나아갈 수 있는 후보 중 하나를 선택한다.
> 2. **탐색하기 (Explore)**: 선택한 상태를 가지고 재귀 함수를 통해 다음 단계를 진행한다. 
> 3. **원상복구하기 (Backtrack)**: 탐색이 끝나고 돌아왔을 때, 내가 선택했던 흔적을 다시 지워놓는다. 
>
> 즉, 무작정 모든 길을 다 뒤지는 것이 아니라 가봤다가 아니면 흔적을 지우고 되돌아와서 다른 경우를 시도하는 효율적인 **완전탐색(Brute-Force)**이다.

해당 문제의 경우, 방문이 끝난 경우에는 visited를 False로 다시 되돌리는 백트래킹 과정을 거친다. 앞 예제와 동일하게 [1, 4, 7, 0]이 들어온다고 가정하고 DFS(1)을 한다고 가정하고 구조를 짜보면 다음과 같다.

> 1. 넘어온 숫자를 set에 추가
> 
> 2. 해당 숫자 visited = True
>
> 3. 반복: 남은 숫자들(visited=False인) 뒤에 붙여서 DFS 진행(재귀)
> 
> 4. 반복 종료 후 visited = False로 되돌리기(다른 재귀 덩어리에 방해 안 되게)

<br>
위와 같은 구조를 짜보았다. DFS(1)을 예시로 들어보면

1. set에 1 추가, `visited[1의인덱스] = True`
2. 반복(4, 7, 0) -> 둘 다 방문 안 해봤기 때문에 이어 붙여서 DFS 진행(`DFS(14)`, `DFS(17)`, `DFS(10)`) 
3. DFS(14) -> set에 14추가, visited[4의인덱스] = True 다시 반복문!
4. DFS(14) 기준 visited = [T, T, F, F] 이기 때문에 -> `DFS(147)`, `DFS(140)`

이런 식으로 진행된다! 이러다가 자식들의 재귀가 모두 끝이 나면 `visited[1의인덱스] = False`를 통해 다음 재귀에 영향이 가지 않도록 처리를 해주어야 한다. 

해당 구조를 통해 **파라미터(매개변수)로 visited 접근을 위한 idx가 추가되어야 함**을 깨달았고 이를 고려하여 코드를 작성했다. 


<br>

## 💡 그래서 답은

```python 
def isPrime(num):
    if num < 2:
        return False
    for i in range(2, (num//2)+1):
        if num % i == 0:
            return False
    return True

def solution(numbers):
    answer = 0
    s = set([])
    
    visited = [False] * len(numbers)
    
    def dfs(c, idx):
        s.add(int(c))
        visited[idx] = True
        for i in range(len(numbers)):
            if visited[i] == False:
                dfs(c+numbers[i], i)
        visited[idx] = False
    
    for i in range(len(numbers)):
        dfs(numbers[i], i)
    
    for n in s:
        if isPrime(n):
            answer += 1
    
    return answer
    
```
