# [LV. 3] 단어 변환

[🔎 문제 보러가기](https://school.programmers.co.kr/learn/courses/30/lessons/43163)

## 문제 설명

두 개의 단어 begin, target과 단어 집합 words가 있습니다. 아래와 같은 규칙을 이용하여 begin에서 target으로 변환하는 가장 짧은 변환 과정을 찾으려 합니다.

1. 한 번에 한 개의 알파벳만 바꿀 수 있습니다.
2. words에 있는 단어로만 변환할 수 있습니다.

예를 들어 begin이 "hit", target이 "cog", words가 `["hot","dot","dog","lot","log","cog"]`라면 `"hit" -> "hot" -> "dot" -> "dog" -> "cog"`와 같이 3단계를 거쳐 변환할 수 있습니다.

두 개의 단어 begin, target과 단어 집합 words가 매개변수로 주어질 때, 최소 몇 단계의 과정을 거쳐 begin을 target으로 변환할 수 있는지 return 하도록 solution 함수를 완성해주세요.

### 제한사항

* 각 단어는 알파벳 소문자로 이루어져 있습니다.
* 각 단어의 길이는 3 이상 10 이하이며 모든 단어의 길이는 같습니다.
* words에는 3개 이상 50개 이하의 단어가 있으며 중복되는 단어는 없습니다.
* begin과 target은 같지 않습니다.
* 변환할 수 없는 경우에는 0를 return 합니다.

## 입출력 예

| begin | target | words | return |
| --- | --- | --- | --- |
| `"hit"` | `"cog"` | `["hot","dot","dog","lot","log","cog"]` | `3` |
| `"hit"` | `"cog"` | `["hot","dot","dog","lot","log","cog"]` (target 없는 경우 등) | `0` |

## 💡 그리하여 어떻게 풀었나


### 1. 두 단어가 변환 가능한 관계인지 판정하기 (`canChange`)

글자가 딱 1개만 다른지 확인하려면 두 단어의 같은 자리 글자들을 비교하면서 다른 개수를 세어주면 된다.

```python
def canChange(w1, w2):
    diff = 0
    for i in range(len(w1)):
        if w1[i] != w2[i]:
            diff += 1
    return True if diff == 1 else False

```

### 2. BFS 탐색 함수 구현

BFS를 구현하면서 한 가지 의문이 생겼다. `ans` 값을 큐에서 꺼낼 때(`popleft()`) 올려주면 되는 거 아닌가? 했는데, 이러면 큐에 들어간 순서대로 뒤죽박죽 카운트가 올라가서 거리가 이상하게 커지는 문제가 발생했다.

BFS에서 정확한 최단 거리를 구하려면 다음 두 가지를 지켜야 한다는 것을 깨달았다!

> 1. **방문 체크(`visited`)는 큐에서 꺼낼 때가 아니라, 큐에 넣을 때(Push) 바로 해준다.**
> 2. **큐에 단어만 넣는 게 아니라, `(현재 노드 번호, 지금까지의 거리)` 형태의 튜플로 묶어서 거리를 함께 들고 다닌다!**



즉, 방문 시점과 tovisit에 추가되는 시점 등 알고리즘의 구조를 정확히 제어할 수 있어야 이런 유형의 문제를 완벽하게 풀어나갈 수 있다는 것!!을 배웠다.

## 💡 그래서 답은

```python
from collections import deque

def canChange(w1, w2):
    diff = 0
    for i in range(len(w1)):
        if w1[i] != w2[i]:
            diff += 1
    return True if diff == 1 else False


def solution(begin, target, words):
    words = words + [begin]
    
    # 1. 인접 리스트 형태로 변환
    adj = [[] for _ in range(len(words))]
    for i in range(len(words)):
        for j in range(len(words)):
            # if i번째 단어랑 j번째 단어랑 하나 차이가 나면 간선 연결되니까 adj에 추가
            if canChange(words[i], words[j]):
                adj[i].append(j)
    
    # 2. bfs 구현
    visited= [False] * len(words)
    tovisit= deque([])
    
    def bfs(s):
        tovisit.append((s, 0))
        visited[s] = True
        
        while tovisit:
            vn, dist = tovisit.popleft()
            
            if words[vn] == target:
                return dist
            
            visited[vn] = True

            for n in adj[vn]:
                if not visited[n]:
                    visited[n] = True
                    tovisit.append((n, dist+1))
        return 0
                
            
    # bfs(len(words)-1) (begin 단어로 시작)
    return bfs(len(words)-1)
    
```
