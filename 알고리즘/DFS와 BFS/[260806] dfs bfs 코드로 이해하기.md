## 문제 설명
그래프를 DFS로 탐색한 결과와 BFS로 탐색한 결과를 출력하는 프로그램을 작성하세요.
단, 방문할 수 있는 정점이 여러 개인 경우에는 정점 번호가 작은 것을 먼저 방문하고, 더 이상 방문할 수 있는 점이 없는 경우 종료합니다. 정점 번호는 1번부터 N번까지입니다.

## 입력 조건

첫째 줄에 정점의 개수 N(1 ≤ N ≤ 1,000), 간선의 개수 M(1 ≤ M ≤ 10,000), 탐색을 시작할 정점의 번호 V가 주어진다.

다음 M개의 줄에는 간선이 연결하는 두 정점의 번호가 주어진다. 어떤 두 정점 사이에 여러 개의 간선이 있을 수 있으며, 입력으로 주어지는 간선은 양방향이다.

## 출력 조건

첫째 줄에 DFS를 수행한 결과를, 그다음 줄에는 BFS를 수행한 결과를 출력합니다. (V부터 방문된 점을 순서대로 공백으로 구분하여 출력)

## 입출력 예시
예제 입력 1
```
4 5 1
1 2
1 3
1 4
2 4
3 4
```
예제 출력 1
```
1 2 4 3
1 2 3 4
```
예제 입력 2
```
5 5 3
5 4
5 2
1 2
3 4
3 1
```
예제 출력 2
```
3 1 2 5 4
3 4 5 2 1
```

## 접근 방법 및 풀이 과정

### 0. 사전 준비 및 입력 받기

가장 먼저 문제에 주어진 정보를 적절한 형태로 가공한다. 이 때 문제에서 _**'방문할 수 있는 정점이 여러 개인 경우에는 정점 번호가 작은 것을 먼저 방문하고'**_ 라는 조건을 제공해주었기 때문에, 반드시 adj(인접 리스트)는 정렬하여 준비해야 한다. 

```python
import queue

N, M, V = map(int, input().split())
adj = [[] for _ in range(N+1)]
ans_dfs = [] # dfs 결과를 저장할 리스트
ans_bfs = [] # bfs 결과를 저장할 리스트

for _ in range(M):
    start, end = map(int, input().split())
    adj[start].append(end)
    adj[end].append(start)

for i in range(1, N+1):
    adj[i].sort()
```

### 1. dfs 함수 구현
조금 더 쉬운 dfs 부터 먼저 구현했다. dfs의 경우 크게 어렵지 않다! 우선 재귀다.. 재귀 ㅎㅇ 어서오고. dfs 함수의 흐름은 아래와 같다.

> v(visited) 리스트 초기화([0] * (N+1))
<br> 
매개변수로 받는 c(현재 정점) v에 append
<br> 
v의 인접노드 탐색
<br> 
이 때 visited에 있을 시, continue
<br> 
없을 시, dfs(n) (재귀)

코드로 작성하면 아래와 같다.(참 쉽죠?)

```python
# 1. dfs 함수 구현
dfs_v = [0] * (N+1)
def dfs(c):
    ans_dfs.append(c)
    dfs_v[c] = 1

    for n in adj[c]:
        if dfs_v[n] == 0:
            dfs(n)

dfs(V)
```

<br>

### 2. bfs 함수 구현
bfs는 dfs보다 조금 더 복잡하다고 느꼈다. 그치만 이해하고 문제를 많이 풀어보면 충분히 타파할 수 있는 흐름이라고 생각 !!! 

bfs는 dfs와 달리 queue를 사용해 구현한다. 방문 예정인 정점을 이 queue를 사용해 관리해야 한다. bfs의 전체적인 흐름은 다음과 같다.

> 방문한 정점 리스트(v)와 방문 예정인 tovisit 큐를 준비한다. 
<br>
매개변수로 시작 정점을 입력받는다(s)
<br>
tovisit에 시작 정점을 추가한다.
<br>
tovisit이 빌 때까지 반복한다.
<br><br>
➡️ 큐에서 한 개 주워오기
<br>
➡️ 방문했던 정점이라면 continue
<br>
➡️ 그렇지 않으면 v 리스트 업데이트, ans에 append
<br>
➡️ bfs 진행: 인접 노드들을 tovisit 큐에 추가


```python
# 2. bfs 함수 구현
bfs_v = [0] * (N+1)
tovisit = queue.Queue()
def bfs(s):
    tovisit.put(s)

    while not tovisit.empty():
        u = tovisit.get()
        if bfs_v == 1:
            continue

        bfs_v[u] = 1
        ans_bfs.append(u)

        for v in adj[u]:
            if bfs_v[v] == 0:
                tovisit.put(v)
```
