# [LV. 1] 동영상 재생기

[🔎 문제 보러가기](https://school.programmers.co.kr/learn/courses/30/lessons/340213)

## 문제 설명

당신은 동영상 재생기를 만들고 있습니다. 동영상 재생기는 10초 전으로 이동, 10초 후로 이동, 오프닝 건너뛰기라는 기능이 있습니다. 각 기능에 대한 설명은 다음과 같습니다.

* **`prev`**: 10초 전으로 이동합니다. 현재 위치가 10초 미만인 경우 영상의 처음 위치인 `00분 0초`로 이동합니다.
* **`next`**: 10초 후로 이동합니다. 동영상의 남은 시간이 10초 미만일 경우 영상의 마지막 위치인 `video_len`으로 이동합니다.
* **오프닝 건너뛰기**: 현재 재생 위치가 오프닝 시작 시간(`op_start`) 이상이고 오프닝 끝 시간(`op_end`) 이하인 경우 자동으로 오프닝이 끝나는 위치(`op_end`)로 이동합니다.

동영상의 길이 `video_len`, 기능 수행 직전의 재생 위치 `pos`, 오프닝 시작 시각 `op_start`, 오프닝 끝 시각 `op_end`, 사용자의 입력 `commands`가 매개변수로 주어집니다. 이때 모든 연산이 끝난 후의 최종 위치를 return 하도록 solution 함수를 완성해 주세요.

### 제한사항

* `video_len`, `pos`, `op_start`, `op_end`는 `"mm:ss"` 형태로 주어집니다.
* `mm`은 분, `ss`는 초를 의미하며 두 자릿수로 고정되어 있습니다.
* 각각 `00`분 `00`초 이상 `59`분 `59`초 이하입니다.


* 사용자 입력 `commands`의 길이는 1 이상 100 이하입니다.
* `commands`의 원소는 `"prev"` 또는 `"next"`입니다.
* `op_start`는 항상 `op_end`보다 전 시각에 주어집니다.
* 시작 위치나 명령어 연산 결과가 오프닝 구간인 경우 자동으로 오프닝 끝 위치로 이동합니다.

## 입출력 예

| video_len | pos | op_start | op_end | commands | return |
| --- | --- | --- | --- | --- | --- |
| `"34:33"` | `"13:00"` | `"10:55"` | `"15:00"` | `["next", "prev"]` | `"13:00"` |
| `"10:55"` | `"00:05"` | `"00:15"` | `"06:55"` | `["prev", "next"]` | `"06:55"` |
| `"07:22"` | `"04:05"` | `"00:15"` | `"04:07"` | `["next"]` | `"04:17"` |

## 💡 접근 방법 및 풀이 과정

시작하기에 앞서, 굉장히 바보같은 접근으로 인해 안 해도 될 고생을 했다는 것을 짚고 ^^. 시작하도록 하겠습니다. 예외케이스를 가장 먼저 적어나갔다.

1. prev 일 때
   - 일반적: 그냥 -10
   - 10초를 뺐을 때 초가 음수가 되는 경우 -> 분에서 가져오기 or 00:00 되기

2. next 일 때
   - 일반적: 그냥 +10
   - 10초를 뺐을 때 초가 60 이상이 되는 경우 -> 분 +1 하기 or radio_len 되기

3. 그 외 공통 예외 케이스
   - 명령어를 실행하기 전에, 오프닝 구간 안에 있다면 오프닝 끝 구간으로 건너 뛰기

또한 현재 입력은 "mm:ss" 형태의 문자열로 되어 있는데, 계산하기엔 정수의 형태가 편하다고 생각했다. 그래서 정수 배열의 형태(`[mm, ss]`)로 바꾸어 계산을 진행했다. 

근데 코드를 짜다가 생각해보니! 대소 비교를 하려면 정수 형태로의 변환이 필수적이었다. (~~여기서 뭔가 이상한 걸 느꼈다면 우린 조금 달라졌을까~~) 그리하여

> ### 문자열 형태(mm:ss) / 배열 형태([mm, ss]) / 정수 형태 (mmss) 세개의 상태를 와리가리하는 최악의 코드가 탄생했다.

그렇게 해결한 코드는 아래와 같다.. (쪽팔리긴한데뭐어쩌겟음..내가한삽질인데)

```python
def strToArr(target):
    return [int(target[:2]), int(target[3:])]

def arrToInt(target):
    return (target[0] * 100) + target[1]

def arrToStr(target):
    answer = "0" if target[0] < 10 else ""
    answer += str(target[0])
    
    answer += ":"
    
    ss = target[1]
    answer += "0" if target[1] < 10 else ""
    answer += str(target[1])
    
    return answer

def processCommand(cmd, ctime, video_len, op_start, op_end):
        # ctime = [mm, ss]의 형태
        
        # 오프닝 구간인 경우 오프닝이 끝나는 위치로 이동
        if arrToInt(strToArr(op_start)) <= arrToInt(ctime) <= arrToInt(strToArr(op_end)):
            ctime = strToArr(op_end)
            
        if cmd == "prev":
            if ctime[0] == 0 and ctime[1] < 10:
                ctime = [0, 0]
            elif ctime[1] < 10:
                ctime[0] -= 1
                ctime[1] += 50
            else:
                ctime[1] -= 10
        elif cmd == "next":
            if ctime[1] >= 50:
                ctime[0] += 1
                ctime[1] -= 50
            else:
                ctime[1] += 10
            
        # video_len보다 크면 video_len으로 변경
        if arrToInt(ctime) > arrToInt(strToArr(video_len)) :
            ctime = strToArr(video_len)
        
        # 오프닝 구간인 경우 오프닝이 끝나는 위치로 이동
        if arrToInt(strToArr(op_start)) <= arrToInt(ctime) <= arrToInt(strToArr(op_end)):
            ctime = strToArr(op_end)
            
        return ctime
    
def solution(video_len, pos, op_start, op_end, commands):
    time = strToArr(pos)
    
    for cmd in commands:
        time = processCommand(cmd, time, video_len, op_start, op_end)
    return arrToStr(time)

```

```python
def minToSec(time):
    return (int(time[:2]) * 60) + int(time[3:])

def secToMin(time):
    mm = str(time//60)
    mm = ("0" + str(time//60)) if time//60 < 10 else str(time//60)
    ss = ("0" + str(time%60)) if time%60 < 10 else str(time%60)
    return mm + ":" + ss

def processCommand(cmd, pos, video_len, op_start, op_end):
        if cmd == "prev":
            if pos-10 < 10:
                pos = 0
            else:
                pos -= 10
                
        elif cmd == "next":
            if pos+10 > video_len:
                pos = video_len
            else:
                pos += 10
        
        if op_start <= pos <= op_end:
            pos = op_end
        
        return pos
    
def solution(video_len, pos, op_start, op_end, commands):
    video_len, pos, op_start, op_end = minToSec(video_len), minToSec(pos), minToSec(op_start), minToSec(op_end)
    
    if op_start <= pos <= op_end:
            pos = op_end
            
    for cmd in commands:
        pos = processCommand(cmd, pos, video_len, op_start, op_end)
        
    return secToMin(pos)

```
