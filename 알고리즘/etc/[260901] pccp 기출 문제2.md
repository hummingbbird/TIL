# [LV. 1] 붕대 감기

[🔎 문제 보러가기](https://school.programmers.co.kr/learn/courses/30/lessons/250137)

## 문제 설명

수웅이는 붕대 감기 기술을 사용하는 캐릭터를 가지고 있습니다. 붕대 감기는 $t$초 동안 붕대를 감으면서 1초마다 $x$만큼 체력을 회복합니다. $t$초 동안 붕대를 연속으로 감는 데 성공하면 $y$만큼의 체력을 추가로 회복합니다.

게임 캐릭터에는 최대 체력이 존재해 체력이 최대 체력보다 커질 수는 없습니다. 반면 붕대 감기를 사용 중 몬스터에게 공격을 당하면 기술이 취소되고, 공격을 당하는 순간에는 체력을 회복할 수 없습니다. 또한 붕대 감기가 취소되거나 기술이 끝나면 그 즉시 붕대 감기를 다시 사용하며, 연속 성공 시간은 0으로 초기화됩니다.

몬스터의 공격을 받으면 정해진 피해량만큼 체력이 줄어듭니다. 이때 몬스터가 공격할 때마다 캐릭터의 체력이 0 이하가 되면 캐릭터가 죽으며 더 이상 체력을 회복할 수 없습니다.

붕대 감기 기술의 정보 `bandage`, 최대 체력 `health`, 몬스터의 공격 패턴 `attacks`가 매개변수로 주어집니다. 몬스터의 공격이 끝난 후 캐릭터의 남은 체력을 return 하도록 solution 함수를 완성해 주세요. 만약 몬스터의 공격을 받고 캐릭터의 체력이 0 이하가 되어 죽는다면 `-1`을 return 합니다.

### 제한사항

* `bandage`는 `[t, x, y]` 형태로 주어집니다.
* $t$는 붕대 감기 시간, $x$는 1초당 회복량, $y$는 붕대 감기 성공 시 추가 회복량을 의미합니다.
* $1 \le t \le 50$
* $1 \le x, y \le 100$


* `health`는 캐릭터의 최대 체력을 의미합니다.
* $1 \le health \le 1,000$


* `attacks`는 몬스터의 공격 정보를 담고 있습니다.
* `attacks[i]`는 `[attack_time, damage]` 형태로, `attack_time`은 공격 시간을, `damage`는 피해량을 의미합니다.
* $1 \le attacks의 길이 \le 100$
* 공격 시간은 오름차순으로 정렬되어 주어집니다.
* 몬스터의 공격 시간은 서로 중복되지 않습니다.



## 입출력 예

| bandage | health | attacks | return |
| --- | --- | --- | --- |
| `[5, 1, 5]` | `30` | `[[2, 10], [9, 15], [10, 5], [11, 5]]` | `5` |
| `[3, 2, 7]` | `20` | `[[1, 15], [5, 16], [8, 6]]` | `-1` |
| `[4, 2, 7]` | `20` | `[[1, 15], [5, 16], [8, 6]]` | `-1` |
| `[1, 1, 1]` | `5` | `[[1, 2], [3, 2]]` | `3` |

# 💡 접근 방법 및 풀이 과정

레벨 1은 확실히 .. 쉽군아. 약간 우테코 1주차 과제 푸는 것 같았다. 케이스 분리를 명확히 하고 각 상황별로 일어나야 할 일을 잘 나누어주면 된다.

1. 공격 시간인 경우
   - 공격 시간인 경우, 붕대 감기는 진행하지 않는다.
   - 체력 감소, 연속 성공 초기화
   - 판단: 체력이 0보다 작아진 경우 `return -1`
   - 종료 이벤트: 다음 공격으로 변경(`attack_idx += 1`)

2. 공격 시간이 아닌 경우
   - 체력 회복, 연속 성공 +1
   - 판단: 목표 연속 성공에 도달한 경우, 체력 증진 and 연속 성공 초기화
   - 판단: 최대 체력 이상이 된 경우, 최대 체력으로 교체

3. 공통
    - cnt += 1

언제 어떤 일이 일어나는지만 정확히 구분하면, 그 다음부터는 크게 어렵지 않다. 주의해야할 지점들은  while 종료 조건, 비교 연산자의 등식 포함 여부 정도?

## 💡 그래서 답은

```python
def solution(bandage, health, attacks):
    t, x, y = bandage
    max_health = health
    cnt, sequence = 1, 0
    attack_idx = 0
    
    while attack_idx < len(attacks):
        n_attack = attacks[attack_idx]
        
        # 공격 시간인 경우
        if n_attack[0] == cnt:
            health -= n_attack[1]
            sequence = 0
            # 체력이 0보다 작아진 경우
            if health <= 0:
                return -1
            attack_idx += 1
        
        # 공격 시간이 아닌 경우
        else:
            health += x
            sequence += 1
            
            # 연속 성공일 경우
            if sequence == t:
                health += y
                sequence = 0
            
            # 최대 체력 이상을 가지려고 할 때
            if health > max_health:
                health = max_health
        
        cnt += 1
            
    return health

```
