# [LV. 2] 퍼즐 게임 챌린지

[🔎 문제 보러가기](https://school.programmers.co.kr/learn/courses/30/lessons/340212)

## 문제 설명

친구들과 함께 퍼즐 게임을 진행하고 있습니다. 각 퍼즐은 난이도와 소요 시간이 정해져 있으며, 숙련도에 따라 클리어하는 데 걸리는 시간이 달라집니다.

* **퍼즐 해결 규칙**:
* 현재 퍼즐의 난이도(`diff`)가 나의 숙련도(`level`)보다 **작거나 같으면**, 퍼즐을 연달아 틀리지 않고 한 번에 해결합니다. (소요 시간: `time_cur`)
* 현재 퍼즐의 난이도(`diff`)가 나의 숙련도(`level`)보다 **크면**, 퍼즐을 총 `diff - level`번 틀리게 됩니다.
* 틀릴 때마다 이전 퍼즐의 소요 시간(`time_prev`)만큼 시간을 더 사용한 뒤 현재 퍼즐을 다시 풀어 해결합니다. (즉, 틀릴 때마다 `time_cur + time_prev` 만큼의 시간이 소모되며, 마지막에 정답을 맞히는 `time_cur`가 한 번 더 더해집니다.)



제한 시간(`limit`) 내에 모든 퍼즐을 해결하기 위해 필요한 최소한의 숙련도(`level`)의 최솟값을 return 하도록 solution 함수를 완성해 주세요.

### 제한사항

* `diffs`의 길이(= 퍼즐의 개수)는 $1$ 이상 $300,000$ 이하입니다.
* `diffs[i]`는 $i$번째 퍼즐의 난이도이며, $1$ 이상 $100,000$ 이하입니다.


* `times`의 길이는 `diffs`의 길이와 같습니다.
* `times[i]`는 $i$번째 퍼즐을 소요하는 기본 시간이며, $1$ 이상 $10,000$ 이하입니다.


* `limit`은 전체 퍼즐을 해결해야 하는 제한 시간이며, $1$ 이상 $10^{15}$ 이하입니다.
* 숙련도의 최솟값은 $1$이며, 모든 퍼즐을 제한 시간 내에 해결할 수 있는 데이터만 입력으로 주어집니다.

## 입출력 예

| diffs | times | limit | return |
| --- | --- | --- | --- |
| `[1, 5, 3]` | `[2, 4, 7]` | `30` | `3` |
| `[1, 4, 42]` | `[1, 9, 2]` | `35` | `2` |
| `[1, 32, 53, 24, 85, 25, 42]` | `[3, 10, 34, 13, 4, 6, 1]` | `345` | `33` |
| `[1, 999, 1000, 1000]` | `[1, 2, 5, 2]` | `3000` | `222` |

# 💡 접근 방법 및 풀이 과정

일반적인 구현문제라고 생각했다. 주어진 조건에 따라 올바른 행동을 하고, 반복의 종료 조건을 적절히 걸어주는 방식으로 해결했다. 우선 문제에 주어진 조건들을 수도코드로 작성했다.

```
각 레벨에서,
- Diff <= level이면, time_cur만큼 시간 써서 해결
    - time_cur 사용
- Else 이면
    - 퍼즐을 diff-level번 틀림
    - 시간 time_cur 사용 해야함
    - time_prev 사용해서 이전 시간만큼 퍼즐 풀어야함. 
        - 즉, 한 번 틀릴 때마다 time_cur + time_prev 사용
        - 즉, (diff-level) * (time_cur + time_prev) + time_cur 사용

제한시간 limit 존재. 제한 시간 내에 퍼즐을 모두 해결하기 위한 숙련도의 최솟값을 구하라. (양의 정수)
```

위와 같은 과정을 함수로 분리하고, level을 1부터 하나씩 올려 퍼즐을 해결할 수 있을 때까지 반복하는 방식으로 코드를 작성하였다.

```python
def isPossible(diffs, times, limit, level):
    for i in range(len(diffs)):
        diff, time_cur = diffs[i], times[i]
        
        if diff <= level:
            limit -= time_cur
        else:
            limit -= (diff-level) * (time_cur + times[i-1]) + time_cur 
        if limit < 0:
            return False
    return True

def solution(diffs, times, limit):
    level = 0
    while True:
        level += 1
        if isPossible(diffs, times, limit, level):
            return level
```

```
2. e가 s보다 커질 때까지 반복(while s <= e)
3. mid 값 설정 후, isPossible() 실행
    - 가능하면 mid의 앞으로 범위 바꾸기(e = mid-1)
    - 불가능하면 mid의 뒤로 범위 바꾸기(s = mid+1)
```

## 💡 그래서 답은

```python
def isPossible(diffs, times, limit, level):
    for i in range(len(diffs)):
        diff, time_cur = diffs[i], times[i]
        if diff <= level:
            limit -= time_cur
        else:
            limit -= (diff-level) * (time_cur + times[i-1]) + time_cur 
        if limit < 0:
            return False
    return True

def solution(diffs, times, limit):
    s, e = 1, max(diffs)+1
    answer = 0
    while s <= e:   
        mid = (s+e) // 2 
        if isPossible(diffs, times, limit, mid):
            answer = mid
            e = mid-1
        else:
            s = mid+1
    return answer

```
