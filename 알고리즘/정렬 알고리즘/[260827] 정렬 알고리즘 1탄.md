# 정렬 알고리즘 1탄: 시간 복잡도가 O($n^{2}$ )인 알고리즘

오늘은 베이직 정렬 알고리즘들에 대해 공부를 해보았다. 그 전에 정렬 알고리즘은 추가적인 메모리 사용 유무에 따라 in-place와 out-of-place로 나눌 수 있다. 

- **In-place**: 추가 메모리를 사용하지 않음
    - ex) basic 3개, quick sort, heap sort
- **Out-of-place**: 추가 메모리 공간 사용
    - ex) merge sort, counting sort, radix sort

<br>


## 🫧 Bubble Sort

- 기본 of  기본, 최댓값 맨 뒤로 보내기를 반복하는 알고리즘
- 인접한 거 비교해서 맨 뒤로 보내기 반복
- Θ(n²), in-place, stable

<!-- 이미지1 -->

```python
# 최댓값 맨 뒤로 보내기
def bubblesort(arr):
  n=len(arr)
  for i in range(n,1,-1):
    # or range(n-1,0,-1), range(i)
    for j in range(i-1):
      if arr[j] > arr[j+1]:
        arr[j], arr[j+1] = arr[j+1], arr[j]
  return arr
```

### ⛏️ Selection Sort

- 최솟값 찾아 앞에 놓기 반복
- 최솟값 index 저장해서(j 반복문), 맨 앞에 놓음(i 반복문)
- Θ(n²) ,in-place, unstable

```python
# 최소를 맨 앞으로
def selectsort(arr):
  n = len(arr)
  for i in range(n):
    min_idx = i
    for j in range(i+1,n):
      if arr[min_idx] > arr[j]:
        min_idx = j
    arr[i], arr[min_idx] = arr[min_idx], arr[i]
  return arr
```

### 🚮 lnsertion Sort

- 하나 골라서 정렬된 곳에 끼워넣기 권법
- 특이한 점: swap되는 경우에만 j 반복문이 continue 되기 때문에 j는 자연스럽게 그 대상을 따라감..!!!
- Θ(n²) ,in-place, stable

```python
# 앞에서부터 하나씩 잡아서 insert 해줌(자기보다 작은 게 나오면 바로 swap)
# i는 처음부터 끝까지, j는 i부터 0까지 scan
def insertionsort(arr):
  n = len(arr)
  for i in range(1, n):
    for j in range(i, 0, -1):
      if arr[j-1] <= arr[j]:
        break
      arr[j-1], arr[j] = arr[j], arr[j-1]
  return arr
```
