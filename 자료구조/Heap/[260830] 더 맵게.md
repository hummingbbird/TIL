## 문제 설명

매운 것을 좋아하는 Leo는 모든 음식의 Scoville 지수를 $K$ 이상으로 만들고 싶습니다. 모든 음식의 스코빌 지수를 $K$ 이상으로 만들기 위해 Leo는 스코빌 지수가 가장 낮은 두 개의 음식을 아래와 같이 특별한 방법으로 섞어 새로운 음식을 만듭니다.

> **새로운 스코빌 지수 = 가장 안 맵지 않은 음식 + (두 번째로 안 매운 음식 $\times$ 2)**

Leo는 모든 음식의 스코빌 지수가 $K$ 이상이 될 때까지 반복하여 섞습니다. 모든 음식의 스코빌 지수를 $K$ 이상으로 만들기 위해 섞어야 하는 최소 횟수를 return 하도록 solution 함수를 완성해주세요. 단, 모든 음식의 스코빌 지수를 $K$ 이상으로 만들 수 없는 경우에는 `-1`을 return 합니다.

### 제한사항

- scoville의 길이는 2 이상 1,000,000 이하입니다.
- $K$는 0 이상 1,030,000,000 이하입니다.
- scoville의 원소는 각각 0 이상 1,000,000 이하입니다.
- 모든 음식의 스코빌 지수를 $K$ 이상으로 만들 수 없는 경우에는 `-1`을 return 합니다.

## 입출력 예

| scoville               | K   | return |
| ---------------------- | --- | ------ |
| `[1, 2, 3, 9, 10, 12]` | `7` | `2`    |

## 💡 접근 방법 및 풀이 과정

힙 문제로 분리되어 있긴 한데 .. 그래서 힙에 쓰이는 함수를 구현해두긴 했는데 .. 왜 힙을 써야되는지 모르겠는 거임! 그래서 걍 틀릴 거 알지만 일단 지금 떠오르는 접근 방식으로 문제를 풀었다.

```python
def solution(scoville, K):
    answer = 0
    scoville.sort(reverse=True)

    # while: 가장 작은 숫자가 K보다 크거나 같아질 때 or len(스코빌) < 2
    while scoville[-1] < K and len(scoville) > 2:
        a, b = scoville.pop(), scoville.pop()
        scoville.append(a+(b*2))
        scoville.sort(reverse=True)
        answer += 1

    return answer

```

> 1. 주어진 배열을 최소힙 형태로 정리(`build_heap`)
>    <br>
> 2. while 반복: 길이가 2보다 작아지거나 제일 작은(arr[0]) 원소의 값이 K보다 커질 때까지 반복
>    <br>
> 3. 가장 작은 두 수 뽑아서 가공 후, append하고 다시 힙 형태로 바꾸기
>    <br>
> 4. answer 또는 -1 반환

```python
def siftdown(r, arr, n):
    c = (2*r) + 1

    if c >= n: return

    if c+1 < n and arr[c] > arr[c+1]:
        c = c+1

    if arr[r] < arr[c]: return

    arr[c], arr[r] = arr[r], arr[c]

    siftdown(c, arr, n)

def build_heap(arr):
    n = len(arr)
    for i in range(n//2-1, -1, -1):
        siftdown(i, arr, n)

    return arr

def solution(scoville, K):
    answer = 0
    scoville = build_heap(scoville)

    while len(scoville) >= 2 and scoville[0] < K:
        a, b = scoville.pop(0), scoville.pop(0)
        scoville.append(a + (b*2))
        build_heap(scoville)
        answer += 1

    if len(scoville) < 2 and scoville[0] < K:
        answer = -1

    return answer
```

## 💡 그리하여 어떻게 풀었나

**알고보니 python은 heap 라이브러리를 제공한단다.**

환장한다 진짜로.

눈물 닦고 구현해놓은 것을 heap 라이브러리로 수정해주었다. 그랬더니 아주 손쉽게 답이 나왔다. 눈물이 났다. 따윽.. 울고 끝나면 안 되니까 찾아봤더니 다음과 같은 이유때문이었다.

> - 나의 코드: 반복 한 번에 O(n)의 시간 복잡도인데 최악의 경우 반복이 n번 일어날 수 있기 때문에 도합 O(n^2)의 .. 최악의 시간복잡도를 가진다.
> <br>
> - heap 라이브러리: O(nlogn)의 시간 복잡도를 가짐.

그래서 오기가 생겼다. heap을 사용하긴 했지만 시간복잡도가 n의 제곱까지 나오는 건 분명히 문제였다. 그리하여 문제가 되는 부분에 대해 심도깊은 토론을 진행했다. (Thanks to gemini) 그 결과 나의 코드는 이런 문제가 있었다.

1. `scoville.pop(0)`을 통해 최솟값을 추출하니 뒤에 있는 데이터를 다 밀어내면서 O(n)이 걸리게 되었다.
2. heap의 형태를 지키기 위해 매번 `build_heap`을 재호출하니 이 때도 매번 O(n)이 걸렸다.

그래서 위에서 문제가 된 지점들을 바꾸어보았다.

1. `pop(0)` 대신 직접 첫 번째, 두 번째 최솟값 추출
2. 섞은 값을 다시 넣을 때 `build_heap` 대신 아래에서 위로 올리는 `siftup` 함수 구현해서 적용

```python
def siftup(arr, idx):
  while idx > 0:
    parent = (idx - 1) // 2
    if arr[parent] > arr[idx]:
      arr[parent], arr[idx] = arr[idx], arr[parent]
      idx = parent
    else:
      break


def siftdown(r, arr, n):
  c = (2 * r) + 1
  if c >= n:
    return
  if c + 1 < n and arr[c] > arr[c + 1]:
    c = c + 1
  if arr[r] < arr[c]:
    return
  arr[c], arr[r] = arr[r], arr[c]
  siftdown(c, arr, n)


def build_heap(arr):
  n = len(arr)
  for i in range(n // 2 - 1, -1, -1):
    siftdown(i, arr, n)
  return arr


def solution(scoville, K):
  answer = 0
  scoville = build_heap(scoville)

  while len(scoville) >= 2 and scoville[0] < K:
    # 첫 번째 최솟값 추출
    a = scoville[0]
    if len(scoville) > 1:
      scoville[0] = scoville.pop()
      siftdown(0, scoville, len(scoville))
    else:
      scoville.pop()

    # 두 번째 최솟값 추출
    b = scoville[0]
    if len(scoville) > 1:
      scoville[0] = scoville.pop()
      siftdown(0, scoville, len(scoville))
    else:
      scoville.pop()

    # 섞은 값 다시 넣기
    new_val = a + (b * 2)
    scoville.append(new_val)
    siftup(scoville, len(scoville) - 1)

    answer += 1

  if len(scoville) == 0 or scoville[0] < K:
    return -1

  return answer

```

import heapq

def solution(scoville, K):
    answer = 0
    heapq.heapify(scoville)
    
    while len(scoville) >= 2 and scoville[0] < K:
        a, b = heapq.heappop(scoville), heapq.heappop(scoville)
        heapq.heappush(scoville, a+(b*2))
        answer += 1
    
    if len(scoville) < 2 and scoville[0] < K:
        answer = -1
        
    return answer
