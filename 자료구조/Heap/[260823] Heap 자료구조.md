## 🧩 Heap 자료구조
- 힙은 **완전 이진 트리**의 구조를 가진다. (완전 이진 트리: 마지막을 제외한 모든 노드에 자식이 꽉 찬 이진 트리)
- **최대 힙** / **최소 힙**: 각각 부모가 자식보다 큰, 자식이 부모보다 큰 힙을 말한다.
- 힙은 완전 이진 트리의 구조를 가지기 때문에, **배열을 사용해 구현**이 가능하다.
    - 왼쪽 자식: i*2 + 1
    - 오른쪽 자식: i*2 + 2
    - 부모: (r-1)//2 **($\lfloor (r-1)/2\rfloor$)**
- 삽입, 삭제 발생 시 재구조화가 필요하다.

## ✍️ 구현해보기

### 1. Sift down
- 원리: 루트부터 시작해서 자식들 중 큰 것과 비교하여 switch 하는 과정
- 과정
  - 자식이 있는지부터 확인
  - 원 자식 or 두 자식 중 큰 아이 찾기
  - 나랑 비교해서 내가 더 작으면 내려가기(switch)
  - 이 과정 반복(재귀 해도 되고 안 해도 되고 내 맘대루 ~)

위 과정을 수도 코드로 작성하면 아래와 같고

```python
def siftdown(r, arr, n):
    # r: 루트 노드 / arr: 배열 / n: 배열의 길이
    왼쪽 자식 idx 찾기(c)

    1) 자식이 없다면 return
    2) 오른쪽 자식이 있고 and 오른쪽 자식이 더 크다면 -> c를 오른쪽 걸로 갱신
    
    3) 부모가 자식보다 크다면 정상 형태이므로 return
    4) 부모 자식 switch

    5) 재귀: switch 한 쪽으로 다시 siftdown 진행
```

코드로 완성하면 아래와 같다.

```python
def siftdown(r, arr, n):
    c = (r*2)+1

    if c >= n: return

    if c+1 < n and arr[c] < arr[c+1]:
        c = c+1
    
    if arr[r] >= arr[c]: return

    arr[r], arr[c] = arr[c], arr[r]

    siftdown(c, arr, n)
```

### 2. Build Heap

위에서 구현한 `siftdown`을 사용해서 힙을 구현할 수 있다. 전체 다 돌릴 필요 없이 리프 노드가 아닌 마지막 부모 노드의 index는 `n//2 - 1`이다. (규칙이라고 한다. 외우자~) 그리하여 해당 index부터 역으로 루트까지 올라가면 점차적으로 heap의 구조를 가지게 된다.

```python
def build_heap(arr):
    n = len(arr)
    for i in range(n//2 - 1, -1 ,-1):
        siftdown(i, arr, n)

    return arr 
```
